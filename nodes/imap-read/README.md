# IMAP Read

Универсальное чтение IMAPS. Нода не изменяет ящик: `EXAMINE`, частичный
`BODY.PEEK[]`, проверка сертификата и имени сервера. Сервер, логин, пароль
передаются только через вход `credentials`; секреты не включаются в результат
и сообщения об ошибках этой ноды. Общий механизм Credentials не изменён.

`rules` — массив `{sender, subjects[]}`: адрес сравнивается целиком без учёта
регистра, темы — по подстроке без учёта регистра. Правила объединяются через
ИЛИ. Пустой массив правил означает все письма, пустой `subjects` — любую тему
у указанного отправителя. Встроенных адресов, тем и бизнес-правил нет.

Пустой checkpoint начинает историю с UID 1. Принимайте `candidate_checkpoint`
только после надёжной записи всего пакета, включая оригиналы и явный карантин.
При повторе с прежним checkpoint возвращаются те же UID; идемпотентность
записи обеспечивается ключом mailbox/folder/UIDVALIDITY/UID. Нода ничего не
фиксирует самостоятельно. `recovery_required` означает смену UIDVALIDITY или
checkpoint за концом ящика; кандидат отсутствует, автоматический сброс запрещён.

История читается ограниченными окнами по 1000 UID и пакетами `batch_size`.
Пустой пакет тоже может иметь `has_more=true`: в UID-окне были пропуски или
неподходящие письма. Продолжайте с кандидатом после записи результата.
Новые письма после снимка UIDNEXT попадут в следующий вызов.

`status=blocked` и `diagnostics.boundary` показывают превышение размера письма,
вложения, числа вложений или метаданных. Кандидат не перескакивает проблемный
UID. Увеличьте лимит или обработайте письмо отдельно; нельзя безусловно
повторять вызов в бесконечном цикле. Граница суммы байтов пакета даёт `ok` с
`has_more=true`.

Выход `archive` — обычный file-объект `{tmp_path, filename, content_type}`.
При Workflow Cloud фабрика должна получить `output_files.archive.file` с
адресом загрузки от оркестратора. Локальный `tmp_path` не является облачным URL
и не гарантирует долговременное хранение. Архивируйте результат до checkpoint.

ZIP содержит `manifest.json`, `messages/<uid>/original.eml`, `metadata.json`
с полным декодированным текстом/HTML, датами, отправителями, темой и всеми
вложениями `parts/<part_id>.bin`. У оригинала и каждого декодированного вложения
есть SHA256. Имена из письма сохраняются в метаданных, но не используются как
пути на диске. Оригинальный MIME сохраняет исходное представление всех частей.

`messages` содержит ограниченные метаданные писем и массивы `attachments`.
Для Excel передайте `archive` в `Excel Read.file`, а элемент `attachments`
в `Excel Read.attachment`: имя, SHA256, attachment_id и archive_entry.
Текст и оригиналы не дублируются в JSON-портах. Весь MIME загружается только
после проверки размера, частями до 64 КиБ. Успешные выходные временные файлы
удаляет среда исполнения по своей политике после передачи потребителям.
